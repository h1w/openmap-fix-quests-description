# Changelog

## 0.1.5

- Награды на выбор активного задания читаются из его принятой записи журнала: запрос по ID в Forever мог отдавать урезанный список. Для «Во имя Света» сохраняются все четыре предмета, включая ещё не закэшированные названия.
- Выбор журнала восстанавливается после чтения, в том числе при ошибке. Подсказки и ссылки привязаны к реальному ID предмета, а не к индексу урезанного списка.
- Блок «Открыть в» перенесён в самый низ карточки: после наград, опыта и денег; при отсутствии наград — после текста и статуса.
- Фон блока переходов продолжает тёмную секцию наград, если она есть; без наград остаётся светлый пергамент. Цвет подписи соответствует фону.
- GitHub Actions проверяет Lua 5.1 и состав ZIP на push/PR; тег `v<версия>` публикует проверенный установочный архив в GitHub Release. ZIP воспроизводим и не включает чужие базы/ресурсы.

## 0.1.4

- Кнопки переходов в путеводители доступны также в активных заданиях, если источник содержит соответствующий ID.
- Отсутствие записи у конкретного источника по-прежнему не создаёт неработающую кнопку; для 96800 доступны DungeonJournal и ForeverGuide, но не AzerothCompendium.
- В игре проверены все три кнопки активного задания 1050; карта, этаж и выбор штатного журнала сохранены.
- Служебный модуль данных ForeverGuide сгруппирован под OpenMap рядом с основным подаддоном; зависимость от ForeverGuide сохранена.

## 0.1.3

- В карточки дополнительных заданий добавлен блок «Открыть в»: DungeonJournal, ForeverGuide, AzerothCompendium, только для загруженных совместимых источников с этим ID.
- Переход открывает страницу именно задания и правильное крыло, независимо от текущего этажа OpenMap; список источников не зависит от приоритета текстовых полей.
- ForeverGuide использует штатный поиск и реальный результат с проверенным ID; без подмены данных и правок его файлов. Ожидание отменяется при смене карточки/поиска или закрытии окна.
- Фильтры и режимы внешних аддонов не отключаются. Ошибки интеграции сообщаются в чат, без перехода на произвольный квест.

## 0.1.2

- Подробности задания на штатных атласах, шрифтах и шаблонах наград Blizzard, без растянутой фоновой текстуры и жирного текста с тенью.
- Кнопка CatQuest «Читать» для открытого в подаддоне задания, с состояниями воспроизведения и очереди; CatQuest необязателен.
- Приоритет текстовых данных: DungeonJournal → ForeverGuide → AzerothCompendium; пустые поля заполняются следующим источником.
- Обычный журнал, карта данжа, этаж и маршруты не переключаются при открытии и чтении карточки.
- Убрана внутренняя декоративная рамка OpenMap поверх нашей вкладки заданий: она больше не перекрывает кнопку CatQuest. На исходных вкладках оформление восстанавливается.
- Исправлена подпись галочки отслеживания: теперь всегда «Отслеживать задание», включённая галочка означает включённое отслеживание.

## 0.1.1

- Дополнительные задания — объединение AzerothCompendium, ForeverDungeonJournal и ForeverGuide, без Questie-подмены.
- Дедупликация по ID, исключение активных и уже выполненных неповторяемых заданий.
- Сохранены фракционные, расовые и классовые ограничения; задания со всех крыльев объединяются.
- Необязательный модуль OpenMapQuestFixGuideData читает установленные файлы данных ForeverGuide в собственное пространство имён. Файлы и настройки источников не меняются, базы не распространяются.

## 0.1.0

- Исправлено ID-сопоставление заданий подземелий и крыльев, включая Монастырь Алого ордена.
- Новая вкладка активных заданий с переносами, целями, прогрессом и отслеживанием.
- Подробности, описание и предметные награды в той же панели без смены карты.
- Сворачиваемые дополнительные задания из Questie с честным указанием непроверенных условий.
- Сохранение прокрутки и изоляция от штатного журнала, других вкладок и маршрутов.
- Обработка поздней готовности базы и фактически выбранной вкладки OpenMap.
